# CVPN webOS — проверенные телевизоры LG

[Русский](TESTED_DEVICES.ru.md) | [English](TESTED_DEVICES.md)

Актуально на **28 октября 2026 года** · Релиз **2.2.6 Stable**

Владелец подтвердил работу CVPN webOS **на четырёх телевизорах LG**. Новая 2.2.6 меняет упаковку и описание, не VPN-код; отдельной полной проверки этой сборки на всех четырёх моделях пока нет. При этом подробность сохранившихся диагностических отчётов различается: успешная работа по подтверждению владельца не равнозначна полному документированному тесту чистой установки последнего IPK.

## Минимальная версия для Homebrew

- **Самая ранняя версия webOS с подтверждённой работой — 4.4.3-22.**
- В карточке Homebrew используем `webosRelease: '>=4.4'`, чтобы не заявлять поддержку непроверенных 4.0–4.3.
- **Это не гарантия работы на каждой прошивке 4.4.x.** Реально проверенная версия — 4.4.3-22. Для других устройств необходимы работающий root, совместимая служба Homebrew, 32-битное ARMv7-окружение и TUN.
- Для webOS **4.0–4.3**, телевизоров без root и установки через LG Content Store подтверждений нет.

## Возможности и ограничения

**CVPN webOS** — клиент **Xray/VLESS** с импортом совместимых конфигураций и подписок и транспортами **TCP, XHTTP, gRPC**. Для gRPC возможен TLS, поддерживаются совместимые конфигурации Reality. Транспорты не являются отдельными VPN-протоколами. Xray-core и бэкенд входят в единый IPK.

Туннелируется поддерживаемый **IPv4**-трафик. При активном маршруте IPv6 по умолчанию VPN не включается, полноценного kill switch и автоподключения после загрузки нет. CVPN Connect работает через **незашифрованный HTTP** на порту 8765, только в доверенной локальной сети. Подписка CVPN необязательна.

## Для расширения официального списка совместимости

- При необходимости провести одинаковые тесты **чистой установки 2.2.5**, VPN, перезагрузки и удаления/повторной установки на каждой модели.
- Для новых телевизоров фиксировать версию webOS, прошивку, root/Homebrew, userspace, TUN и результат.
- Отдельно проверять сон, потерю питания/сети, откат и удаление на других прошивках.

Не публикуй настоящие подписки, UUID VLESS, токены, PIN и домашние IP телевизоров.
