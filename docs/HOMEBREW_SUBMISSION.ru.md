# CVPN webOS 2.2.5 — Публикация в Homebrew Channel

[Русский](HOMEBREW_SUBMISSION.ru.md) | [English](HOMEBREW_SUBMISSION.md)

**На 28 октября 2026 года:** [2.2.5 Stable](https://github.com/mikemandi/cvpn-webos/releases/tag/v2.2.5) опубликована в GitHub Releases вместе с IPK, SHA256SUMS и YAML для Homebrew. **Релиз на GitHub не означает, что приложение уже добавлено в официальный каталог Homebrew Channel.** Одобрение сопровождающих каталога ещё необходимо.

## Что проверить перед подачей заявки

1. **Права:** подтвердить, что код, название и изображения CVPN можно распространять на выбранных условиях. Для собственного кода CVPN пока нет общей открытой лицензии, поэтому сохраняется **pool: non-free**. Программа при этом бесплатна. Не менять категорию на main до явного решения правообладателя.
2. **Сторонние библиотеки:** Xray-core распространяется под **MPL-2.0**, для QR-компонентов указаны **MIT / Apache-2.0**. Сохранять соответствующие уведомления и возможность получить исходники Xray по версии в IPK.
3. **Скриншоты:** использовать настоящие экраны приложения в пустом состоянии, без личных подписок, UUID, рабочих PIN и IP телевизора. В репозитории есть [английские и русские снимки](../assets/screenshots).
4. **Ограничения:** честно указать обязательный root/Homebrew, только IPv4, блокировку при активном IPv6, отсутствие универсального kill switch и автоподключения при старте, управление по HTTP только в доверенной LAN.
5. **Тесты:** не обещать совместимость всех LG. Описать реально проверенные устройства и ещё не завершённые сценарии сна, падения сети, обновлений и отката.
6. **Использование ИИ:** действующие [правила Homebrew](https://github.com/webosbrew/apps-repo) требуют существенного участия разработчика в проверке и тестировании ИИ-помощи, а также её явного раскрытия в PR. Не включать сведения о пиратстве или обходе DRM.

## Порядок публикации

1. Проверь [официальный выпуск v2.2.5](https://github.com/mikemandi/cvpn-webos/releases/tag/v2.2.5): IPK, SHA256SUMS, su.cvpn.webos.manifest.json, su.cvpn.webos.yml, рабочие ссылки, иконку и хеши.
2. Если нужно, пересоздай YAML скриптом **scripts/make-homebrew-entry.py**. Используй именно IPK версии 2.2.5, а не 2.2.4.
3. Создай fork [webosbrew/apps-repo](https://github.com/webosbrew/apps-repo). Добавь **packages/su.cvpn.webos.yml**, сохрани **pool: non-free**, пока не выбрана собственная открытая лицензия.
4. Приложи настоящие безопасные скриншоты, честное описание, модель угроз и сведения о проверенных LG.
5. После проверки владельцем создай PR в каталог и сообщи, что применялся ИИ, какие тесты проводились вручную, какие риски остаются и кто поддерживает проект.
6. Дождись подтверждения сопровождающих; **до принятия PR не называй приложение доступным в официальном каталоге**.

Ссылки: [правила подачи](https://repo.webosbrew.org/submit) · [репозиторий каталога](https://github.com/webosbrew/apps-repo) · [черновик PR](HOMEBREW_PR_DRAFT.md).

## Что устанавливает пользователь

На телевизоре уже должен быть root и Homebrew. После этого достаточно одного **All-in-One IPK**: он содержит Launcher, Xray, Go-бэкенд и Engine, подготовка выполняется автоматически. Пользователи могут подключать совместимые сторонние конфигурации без подписки CVPN.

Нельзя автоматически изменять системные права LG ради установки на несовместимом устройстве. Подробности: [Безопасность](SECURITY.ru.md), [Ограничения](RELEASE_LIMITATIONS.ru.md), [Лицензии](../LICENSE-PUBLISHING-REVIEW.ru.md).
