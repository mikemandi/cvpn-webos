# CVPN webOS v2.2.5 — черновик заявки в каталог Homebrew

[Русский](HOMEBREW_PR_DRAFT.ru.md) | [English](HOMEBREW_PR_DRAFT.md)

Этот текст предназначен для проверки владельцем. **Саму заявку в каталог следует подавать на английском** по [подготовленному шаблону](HOMEBREW_PR_DRAFT.md).

**Заголовок:** Добавить CVPN webOS — Xray/VLESS для LG с TCP, XHTTP и gRPC

**Суть заявки:**

- CVPN webOS — бесплатный **Xray/VLESS-клиент с транспортами TCP, XHTTP и gRPC** для LG с root, совместимым Homebrew Channel, 32-битным окружением ARMv7 и TUN.
- Импортируются совместимые `vless://`-ссылки, конфигурации VLESS/Reality, HTTPS-подписки и Xray JSON **любых провайдеров**. Для gRPC также поддерживается TLS. TCP, XHTTP и gRPC — транспорты, а не отдельные VPN-протоколы. Подписка CVPN необязательна.
- Все компоненты (Launcher, Xray-core, Go-бэкенд, Engine и восстановление сети) поставляются в одном All-in-One IPK и не требуют загрузки исполняемых файлов с интернета на телевизор при первом запуске.
- **Ограничения:** только IPv4, запрет подключения при активном маршруте IPv6, нет универсального kill switch и автозапуска VPN. HTTP-панель на порту 8765 предназначена исключительно для доверенной LAN.
- **Аппаратные тесты:** LG 55UK6450PLC (webOS 4.4.3-22, 05.50.70) использовался для базовой проверки установки, QR, VPN IP Нидерландов, YouTube, переподключения и обычного выключения. Изменения интерфейса 2.2.5 также подтверждены на LG, но совместимость других моделей не обещается.
- **ИИ-помощь:** инструменты ИИ использовались при разработке, дизайне, подготовке документации и тестах. Владелец проверял код и продукт на реальном LG. Независимого аудита безопасности не проводилось.
- **Лицензирование:** приложение бесплатно, но собственный код CVPN распространяется по **проприетарной лицензии с бесплатным использованием**, поэтому категория **pool: non-free** сохранена. Права Xray-core по MPL-2.0 и QR-компонентов по MIT/Apache-2.0 остаются неизменными.
