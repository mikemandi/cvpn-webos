# CVPN webOS 2.0.0 Stable — результаты

## Реальное устройство (сообщено владельцем LG)

RC5: успешное обновление, сохранность профилей, проверка `doctor`, работа VPN по LAN и Wi-Fi, внешний IP VPN на 2ip.io, работа YouTube, сценарии перезапуска/смены серверов и восстановления. Это подтверждает RC5 на **одном** конкретном телевизоре; пакет Stable из этого архива ещё не запускался на реальном LG.

## Локальная offline-сборка

- Исходники backend: изменена только константа версии `2.0.0-rc5` → `2.0.0`.
- Engine: изменена только маркировка версии `0.1.4-rc5` → `0.1.4`.
- Go 1.23.2 (`CGO_ENABLED=0 GOOS=linux GOARCH=arm GOARM=7`) — успешно, но toolchain устарела для публичного релиза.
- `go test -race`, `go vet`, Go unit tests, синтаксис POSIX shell, контроль SHA-256 — успешно.
- Автономные тесты механизма обновления и отката, проверки отказа при активном VPN — успешно.
- Никакие команды с реальными сетевыми настройками телевизора из тестовой среды не выполнялись.

## Что не проверено

- Stable-пакет на физическом LG; обратная совместимость на других моделях и версиях webOS.
- Аварийное выключение питания во время обновления; реальные DNS/IPv6 leak-тесты на оборудовании.
- Защита HTTP-панели в недоверенной сети (не предусмотрена).
- Публичная сборка и криптографическая подпись Go 1.27.3/артефактов.
