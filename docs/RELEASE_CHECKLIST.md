# Дорожная карта публичного Production Release

Пакет 2.0.0 Stable выпускается только как обновление работающей RC5 конкретного совместимого LG; это не заявление о завершении всех публичных production-требований.

## Уже подтверждено владельцем на RC5

- [x] Обновление RC4.9 → RC5 и успешный `doctor`.
- [x] Сохранность профилей после обновления.
- [x] LAN и Wi-Fi, реальная работа YouTube и внешний адрес VPN.
- [x] Переключение серверов, перезагрузка и восстановление после Stop/Start (по сообщению владельца).

## Открыто перед широким распространением

- [ ] Go 1.27.3 или последняя поддерживаемая toolchain; воспроизводимые CI-бинарники и подписи.
- [ ] Модель защиты локального HTTP; TLS/безопасный способ сопряжения или явно ограниченный способ управления.
- [ ] Независимые DNS/IPv6-тесты и политика IPv6 (пока Engine fail-closed).
- [ ] Транзакционное обновление с восстановлением после пропадания питания.
- [ ] Подтверждённый чистый установщик с нуля и корректный IPK Launcher.
- [ ] Поддержка и QA на нескольких моделях/версиях webOS; матрица совместимости.
- [ ] Внешний security review, зависимости Xray-core и CVE; безопасность поставки.

Перед применением Stable рекомендуется короткий `check/install/doctor`, а не новый круг стресс-тестирования уже проверенного RC5.
