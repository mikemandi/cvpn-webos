# CVPN webOS 2.2.5 — чек-лист распространения

Дата обновления: **28 октября 2026 года** · [Релиз Stable](https://github.com/mikemandi/cvpn-webos/releases/tag/v2.2.5)

**Релиз Stable опубликован**, но работа над качеством и совместимостью не закончена. Это внутренний список проверок перед расширением аудитории и заявкой в каталог Homebrew.

## Уже выполнено

- [x] В репозитории опубликованы исходники, инструкции и официальный IPK версии **2.2.5**.
- [x] Автоматические Go/CI, проверка сборки ARMv7, целостности IPK и тесты установщика/интерфейса пройдены.
- [x] Проверены пользовательские сценарии на LG 55UK6450PLC для базовой All-in-One версии: QR, VPN, IP выхода, YouTube, отключение/подключение и обычное выключение/включение.
- [x] В версии 2.2.5 владелец подтвердил улучшения экрана QR/подготовки и навигации с пульта.
- [x] Подготовлены обезличенные демонстрационные скриншоты настоящего приложения на русском и английском без подписок, личных IP, PIN и UUID.
- [x] README, угрозы безопасности и ограничения описаны без обещаний полного kill switch, IPv6 или защиты локального HTTP.

## Что не завершено

- [x] Выбрана **проприетарная лицензия с бесплатным использованием** для собственных материалов CVPN; [LICENSE](../LICENSE.ru.md) опубликована.
- [ ] Отдельно подтвердить правообладателей и происхождение всех материалов, включая изображения, код сторонних авторов и вклад ИИ. См. [лицензионный аудит](../LICENSE-PUBLISHING-REVIEW.ru.md).
- [ ] Повторно проверить обязанности по исходникам Xray MPL-2.0 и уведомления QR MIT / Apache-2.0 для публично распространяемого IPK.
- [ ] Протестировать **чистую установку 2.2.5** на дополнительных версиях webOS и Homebrew.
- [ ] Провести систематические проверки пропадания питания, сети, сна/пробуждения, rollback, удаления и сохранности данных на нескольких моделях.
- [ ] Провести независимый анализ модели безопасности LAN/HTTP, pairing/session/CSRF, маршрутов, DNS и IPv6.
- [ ] После одобрения владельцем подать PR в официальный [каталог Homebrew](https://github.com/webosbrew/apps-repo) с описанием ИИ-помощи и реальными аппаратными тестами.

## Сигналы для остановки распространения

Потеря обычной сети после завершения VPN, невозможность восстановить маршруты/DNS, исчезновение приватных профилей, непреднамеренная публикация ключей/токенов или необходимость обходить root-права на неподдерживаемой прошивке.
